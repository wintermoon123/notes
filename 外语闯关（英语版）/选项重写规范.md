# 选项重写规范（基于联网调研）

> 依据来源（2026-11-16 联网查证）：
> - **Cambridge Learner Corpus**（5500 万词 / 20 万份考卷 / 215 个国家 / 143 种母语 / 32M 词错误编码）——中国学习者高频错误：时态、主谓一致、标点、冠词、介词
> - **English Grammar Profile**（O'Keeffe & Mark, 剑桥）——按 CEFR 分级的「学习者真实已掌握语法」
> - **English Vocabulary Profile**（EVP）——CEFR 分级词汇表
> - **ESLVista 母语者对比研究**——中文母语者负迁移十大错误 + 8 条典型 Chinglish 句式
> - **languages.dk Scenarios**、**real-life service dialogues**——旅游/餐饮/酒店真实对话语料

---

## 一、诊断：现有选项的三个问题

### 问题 1 · 干扰项「一眼看穿」，无辨析价值

现有 80 题的干扰项几乎全部是**语法残缺**（`Give me a large iced latte` / `Could we starting with the soup` / `Yes receipt`）。

母语者绝不会这样说话，学习者靠排除法即可通关，**训练不到任何真实能力**。而真实场景里真正卡住人的从来不是「缺冠词」。

### 问题 2 · 正确项「像教科书，不像人话」

`Could we start with the soup, please?` 语法无可挑剔，但缺真实语料支撑——真实对话里更常见的是 `I'll have…` / `Could I see…` / `What do you recommend?` 这类**高频固定搭配（chunks）**。

Cambridge 的语用学研究（Pawley & Syder 的 nativelike selection）指出：母语者不是逐词造句，而是从**共享的惯用短语库**里挑现成块。教学也应教 chunk。

### 问题 3 · 缺失了真正的三类难点

调研后确认，真实场景的障碍集中在三层，而现有题库三层全空：

| 层 | 名称 | 说明 | 调研依据 |
|---|---|---|---|
| **L1** | **语域失当** | 语法全对，但场合不对 | CEFR B2 描述词：能"confidently, clearly and politely in a formal or informal register, appropriate to the situation" |
| **L2** | **搭配错误** | 结构对，动词/名词搭档错 | Chinglish 典型：`reply me` / `open the air conditioner` / `discuss about` / `the price is very expensive` |
| **L3** | **话轮功能错** | 回答了，但答的不是这个 | 该问的句型用成陈述、该确认的用成提问 |

## 二、新出题纪律（每题强制）

### 2.1 四选项结构

```
1 个正确项  +  L1 语域失当  +  L2 搭配错误  +  L3 话轮功能错
```

**硬性要求**：三个干扰项**全部语法正确**、**全部读起来像母语者会说的话**，各有一个可诊断的真实缺陷。

**例外**：可在 20% 的题目中保留 1 个「L2·母语负迁移」干扰项（如 `There have many people…`），因为中文母语者的负迁移正是最值得训练的靶点——但它必须**独立成项**，不能靠排除法秒排除。

### 2.2 正确项标准

- 必须是**真实语料中确实在用**的表达，优先用高频固定搭配（chunk）。
- 长度、正式度要与场景匹配（酒店前台 ≠ 朋友聊天）。
- 不得使用任何未在语料中出现的自造句式。

### 2.3 干扰项标注

每道题的解析必须写清**三件事**：
1. 正确项为什么对（给出 chunk / 语用规则）；
2. L1 项错在哪个语域边界；
3. L2 / L3 项分别错在哪。

## 三、真实语料短语库（正确项取材表）

### 3.1 餐饮服务（来自 real-life service dialogues + languages.dk Scenarios）

| 功能 | 真实表达 |
|---|---|
| 要菜单 | `Could I see the menu, please?` |
| 要推荐 | `What do you recommend?` / `What would you recommend?` |
| 点菜 | `I'll have the grilled salmon, please.` / `For my main course, I'll have the steak, medium-rare.` |
| 要水 | `Could I have a glass of water, please?` |
| 询问素食 | `Do you have any vegetarian options?` |
| 询问食材/过敏 | `Does this dish contain nuts?` |
| 要餐巾 | `Could we have some extra napkins, please?` |
| 结账 | `Could I have the bill, please?` |
| 刷卡 | `Can I pay with a credit card?` |
| 投诉菜品 | `I'm sorry, but this steak is overcooked.` |
| 打包 | `Could I get a box to go, please?` |
| 追加要点 | `I'll have the club sandwich with fries, please, and a sparkling water.` |

## 四、三层干扰项的语料化范例

### L1 语域失当

| 场景 | 正确（得体） | L1 干扰项（语域错） |
|---|---|---|
| 咖啡店点单 | `Could I get a large iced latte, please?` | `I would like to procure a large iced latte.` —— `procure` 是公文词汇 |
| 餐厅结账 | `Could we have the bill, please?` | `Could we be provided with the bill, please?` —— 过度正式 |
| 面试反问 | `What does success look like in this role?` | `Would you be so kind as to elucidate the principal duties?` —— 显摆 |
| 酒店报修 | `The air conditioning isn't working.` | `My air conditioning unit is experiencing a malfunction.` —— 书面报告体 |
| 职场求助 | `Let me check my plate — I'll have an answer by 11.` | `Kindly advise whether you might be amenable to assisting me.` —— 迂腐 |

### L2 搭配错误（Chinglish 迁移）

| 正确搭配 | 错误搭配 | 错因 |
|---|---|---|
| `turn on the air conditioning` | `open the air conditioning` | 「开」在不同语境用不同动词 |
| `Could you let me know…` | `Please reply me…` | `reply` 不接人作宾语 |
| `It's very expensive` | `The price is very expensive` | 价格用 high/low，物品才用 expensive |
| `discuss the proposal` | `discuss about the proposal` | `discuss` 后不加 about |
| `make a decision` | `do a decision` | 固定搭配 |
| `It's under my name` | `It's under my name's` | 所属关系 |
| `I need to make a payment` | `I need to pay a payment` | 动词名词同源误用 |
| `I'll check with my manager` | `I'll check my manager` | `check with` 需介词 |

### L3 话轮功能错

| 情境 | 正确 | L3 干扰项 | 错因 |
|---|---|---|---|
| 店员问「要点什么」 | `Could I see the menu, please?` | `I would like to see the menu.` | 该问的句型说成了纯陈述 |
| 对方问「离店时间对吗」 | `That's right — check-out on Friday the 14th.` | `Yes, I am checking out on Friday.` | 确认信息用陈述句更自然 |
| 问「有没有素食」 | `Do you have any vegetarian options?` | `I am vegetarian.` | 陈述代替提问，绕过了服务员的应答 |
| 对方报了改签信息 | `Thanks for letting me know — is Gate 34 far from here?` | `Thanks for letting me know.` | 只致谢没推进任务 |
| 面试官问薪资 | `I've seen the band is around X — I'm flexible.` | `I am flexible.` | 缺少实质信息 |

## 五、附带的语境设计规则

每个决策点额外标注两个字段：

- `func` —— 该题在情境中承担的**功能**（发起 / 请求 / 确认 / 澄清 / 协商 / 拒绝 / 致谢 / 补救）
- `chunk` —— 正确答案对应的**高频固定搭配**，直接进生词本

这样生词本收集的不再是孤立单词，而是**可迁移的语块**（如 `under the name`、`split the bill`、`check it through`），这正是调研指向的有效路径。

## 六、重写执行规范

1. 80 题逐题重写，不复用旧的干扰项。
2. 每题三档干扰项标签固定：`L1 语域` / `L2 搭配` / `L3 话轮`，写进解析。
3. 答案位置继续保持 `ACBD` 循环 → 全局 A/B/C/D 各 20。
4. 全部选项语法正确（可用 ESL 校验工具或人工双查）。
5. 正确项必须能在 §3 语料短语库或同类真实表达中找到出处。
6. 20% 的题目额外加入 1 个「母语负迁移」干扰项，替换掉一个 L1。
