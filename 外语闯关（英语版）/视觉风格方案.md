# 视觉风格方案 · 5 选 1

> 目标：为「英语情境闯关」游戏确定**场景图 + NPC 立绘**的画风。
> 10 个情境需要：10 张场景图（背景）+ 若干 NPC 立绘（每个情境 1–2 个角色，需支持 2–3 种表情）。
> **本文只做风格选定，选定后再批量生成。**

---

## 0. 先说三条硬约束

### 约束 1 · 美术量必须算得过来

| 资产 | 数量 | 说明 |
|---|---|---|
| 场景背景图 | 10 张 | 咖啡店、餐厅、酒店前台、机场值机、地铁站、零售店、机场候机、会议室、办公室、街头 |
| NPC 立绘 | 约 14–18 个 | 10 个情境各 1–2 人：店员、服务员、前台、值机员、地勤、售货员、面试官、同事…… |
| 表情变体 | 每个 NPC 2–3 个 | 待机 / 微笑 / 提示（答错时） |

**总量 ≈ 24–28 张图**。这个量级决定了：

- 风格必须**成体系**（同一套配色、同一套人物比例），否则 20 多张图拼起来像大杂烩
- 每张图要**一次生成到位**，不能反复改（改 20 张的时间成本远高于改 1 张）

### 约束 2 · 场景图不能抢文字

这个游戏是**语言学习工具**，主体是英文文本 + 进度条。场景图的职责是「让学习者知道自己在哪」，不是抢戏。

→ **场景图必须低对比、低饱和、中央留白**，选项文字要有地方放。
→ 参考 itch.io 上 `Cozy Bundle` 的做法：道具是背景，UI 是前景。

### 约束 3 · 立绘要小尺寸可读

选项区是 UI 主体，立绘只占屏幕一角（约 120–200px 高）。这个尺寸下：

- 线条太细会糊 → 需要**粗轮廓**
- 表情太细微看不出 → 需要**夸张的表情差异**
- 深色头发和深色背景会糊在一起 → 需要**浅色背景或描边**

## 1. 五种画风方案

---

### 风格 A · 现代扁平矢量（Flat Vector）

**一句话**：纯色块 + 几何化造型 + 无渐变，最清爽的「教育产品」感。

**视觉特征**
- 物体拆成简单形状，色块前后遮挡营造深度
- 无写实光影，用 strokes + shapes 做阴影和高光
- 线条干净利落，颜色偏柔和

**配色建议**
```
主色    #E6F1FB 天蓝 / #F1EFE8 米白
辅色    #E1F5EE 浅绿 / #FAEEDA 浅琥珀
强调    #378ADD 钴蓝（进度条、正确项）
文字    #0C447C 深蓝 / #2C2C2A 近黑
```
（与方案书现有配色一脉相承，UI 几乎不用改）

**NPC 立绘规格**
- 上半身半身像，正面朝向
- 无五官细节，仅用简单线条表示表情（微笑 = 弧线，提示 = 眉毛角度）
- 尺寸约 1024×1024，透明背景

**参考链接**（可点开对比）
- Behance 扁平矢量系列（经典的 pastel flat 风）：https://www.behance.net/gallery/100232193/Flat-Vector-Illustration-Series
- Behance 房间矢量背景（含餐厅/办公室/博物馆等现成场景）：https://www.behance.net/gallery/179826995/Room-Vector-Backgrounds
- 国内「游戏原画扁平场景设计」风格指南（讲清了扁平风的核心特征与落地流程）：https://www.garts.cn/yxyh/3152.html

**适配度评估**

| 维度 | 评价 |
|---|---|
| 与英语学习产品调性 | ★★★★★ 最贴——像 Duolingo / Babbel 那类教学产品 |
| 文字可读性 | ★★★★★ 背景天然低对比，不抢文字 |
| 10 个场景的一致性 | ★★★★☆ 好，但纯色块容易「千场一面」 |
| NPC 表情表现力 | ★★☆☆☆ 弱——扁平风没有五官细节，答错提示难做 |
| 生成难度 | ★★★★★ 最容易，AI 出图成功率最高 |

**最适合**：想要稳妥、干净、教学产品感，不追求角色魅力。

### 风格 B · 温暖绘本水彩（Picture-book Watercolor）

**一句话**：柔和水彩晕染 + 手绘笔触，像一本会动的生活绘本。

**视觉特征**
- 水彩纸纹，边缘留白不规则，颜色有晕染感
- 线条松弛，造型圆润有手绘味
- 自然、柔和、有故事感

**配色建议**
```
主色    #FAEEDA 暖米 / #EAF3DE 草绿
辅色    #F5C4B3 珊瑚 / #B5D4F4 天蓝
强调    #BA7517 琥珀（进度条、达成态）
文字    #412402 深棕
```
注意：这会**改变现有 UI 的配色体系**——从冷蓝转向暖棕绿，方案书 §2.3 的进度条配色要跟着改。

**NPC 立绘规格**
- 半身像或全身像，带手绘轮廓线
- 可用真实表情（微笑、眨眼、皱眉都能画出来）
- 尺寸约 1024×1536，透明背景

**参考链接**
- Ruth Goodwin 水彩绘本毕业设计（水彩 + 纹理 + 自然主义）：https://ruthgoodwindesigns.co.uk/degree-exhibition
- ReadKidz 十种水彩风格详解（含每种风格的适用/不适用场景分析）：https://www.readkidz.com/it/make/watercolor-childrens-book-illustration
- Blueberry Illustrations 儿童绘本 33 种风格作品集：https://blueberryillustrations.com/childrens-book-illustrations

**适配度评估**

| 维度 | 评价 |
|---|---|
| 与英语学习产品调性 | ★★★☆☆ 偏软，不像学习工具，像绘本 |
| 文字可读性 | ★★★★☆ 水彩背景偏花，需要加半透明白色蒙版 |
| 10 个场景的一致性 | ★★★★☆ 靠统一色调 + 统一角色设计可保证 |
| NPC 表情表现力 | ★★★★★ 最强——真实五官，答错提示可以做出「皱眉」 |
| 生成难度 | ★★★☆☆ 中等，水彩纹理 AI 容易画乱 |

**最适合**：想要温暖、有人情味；如果目标学习者偏小学/初龄，契合度最高。

> ⚠️ **和你的专业背景相关**：你做的是《爱与梦想》绘本课程，绘本插画本就是你的专业领域。这个风格在美术上你能自己把关，不容易被 AI 的「假水彩」骗过去。

### 风格 C · 低多边形 3D 立体（Low Poly 3D）

**一句话**：几何切面 + 柔和光影，像精致的立体模型场景。

**视觉特征**
- 明显的三角面切分，棱角分明
- 无纹理，靠面与面的明度差表现体积
- 配色克制、暖光、软阴影

**配色建议**
```
主色    #EAF3DE 草地绿 / #F1EFE8 石灰
辅色    #FAC775 暖阳黄 / #B5D4F4 天蓝
强调    #639922 橄榄绿（进度条）
文字    #2C2C2A
```

**NPC 立绘规格**
- 3D 渲染的低模人物，正面半身
- 表情用 3D 建模做（可以真的换表情贴图）
- 需要与场景图完全一致的渲染风格（低模 vs 写实混用很跳）

**参考链接**
- Polylusion 低多边形灵感图库（含 A Short Hike、Kentucky Route Zero、Tunic 三个标杆案例的用色与光影分析）：https://polylusion.com/blog/low-poly-3d-art-inspiration
- Behance / Dribbble 搜 `low poly` / `isometric illustration` / `flat shaded 3D` / `Blender diorama`

**适配度评估**

| 维度 | 评价 |
|---|---|
| 与英语学习产品调性 | ★★★☆☆ 偏「游戏」，学习感弱 |
| 文字可读性 | ★★★★☆ 背景色块清楚，但立体光影会让文字区有干扰 |
| 10 个场景的一致性 | ★★★★★ 同渲染管线下最统一 |
| NPC 表情表现力 | ★★★★☆ 可做真实 3D 表情，但 AI 生成立绘难保持同一张脸 |
| 生成难度 | ★★☆☆☆ **最难**——AI 生成低模一致性差，需人工修 |

**最适合**：想要「精致小模型」的质感、能接受较多后期调整。
**风险提示**：AI 出图很难保持 20 多张图的 3D 渲染完全一致（尤其人物脸），这是最容易翻车的方案。

### 风格 D · 像素风（Pixel Art）

**一句话**：16×16 / 32×32 网格手绘像素，复古街机感。

**视觉特征**
- 有限调色板（一般 8–16 色）
- 硬边缘、可见像素颗粒
- 细节靠色块而非线条

**配色建议**
```
限定调色板（建议就用这 8 色）
#2C2C2A 墨  #5F5E5A 暗灰  #F1EFE8 米白  #EAF3DE 浅绿
#FAC775 琥珀  #D85A30 橘红  #378ADD 蓝   #A32D2D 暗红
```

**NPC 立绘规格**
- 16×16 或 24×32 像素的小人，透明背景
- 表情靠 2–3 帧切换
- 缩放需用 `image-rendering: pixelated` 保持锐利

**参考链接**
- Cozy Bundle（14 个 cozy 像素包，20 个角色 + 20 张对话立绘 + 430 个 UI 文件，统一暖色板）：https://itch.io/s/200070/cozy-bundle-ten-packs-for-a-warm-lived-in-game
- Spaceyyy（16×16 像素世界，5000+ 精灵图，含 NPC 立绘）：https://aquumgifts.itch.io/
- Hidden Peak（Cozy RPG 像素资源，含 TAVERN/PUB/INN 室内场景）：https://crazybirdladygames.itch.io/hidden-peak
- Cozy Cabin Interior Set（柔和边缘的像素室内，与本项目 10 个室内场景高度相关）：https://insightfulknight.itch.io/cozy-cabin-interior-set

**适配度评估**

| 维度 | 评价 |
|---|---|
| 与英语学习产品调性 | ★★★☆☆ 复古感强，年轻用户可能反而喜欢 |
| 文字可读性 | ★★★★★ 最好——像素背景信息量低，文字永远清楚 |
| 10 个场景的一致性 | ★★★★★ 统一调色板即可锁定 |
| NPC 表情表现力 | ★★☆☆☆ 16px 下表情很有限，2–3 帧已是上限 |
| 生成难度 | ★★★☆☆ AI 生像素图质量不稳（容易出现「假像素」） |

**最适合**：想要轻量、快、体积小；或者面向有一定怀旧情结的成年学习者。
**注意**：AI 直接生成高质量像素图效果差，**更可靠的路径是「先生成大图 → 像素化处理」**。

### 风格 E · 日式动画半身像（Visual Novel Style）

**一句话**：赛璐璐上色 + 大眼睛 + 半身立绘，日式对话游戏的标准做法。

**视觉特征**
- 清晰描边 + 2–3 层平涂阴影
- 眼睛占脸高约 1/3，鼻子极简
- 头发用大块造型分面（base / shadow / highlight）

**配色建议**
```
主色    #E6F1FB 冷调背景 / #F1EFE8 对话框底
辅色    #CECBF6 淡紫 / #9FE1CB 薄荷
强调    #7F77DD 紫（进度条）/ #D4537E 强调粉
文字    #26215C
```

**NPC 立绘规格**
- 半身像（腰部以上），正面朝向，透明背景
- 每个角色 4–6 种表情（neutral / smile / angry / surprised / sad / talking）
- 分辨率 1024×1024 或 1448×1448

**参考链接**
- VideoCue 日式视觉小说画风完整拆解（含角色 sprite 规格、表情变体数量、背景昼夜变体等规范）：https://videocue.io/looks/visual-novel-anime-2d-portrait
- ZeninClan 视觉小说角色包（4 角色 × 4 表情 = 16 张 PNG，透明背景）：https://zeninclan.itch.io/fantasy-rpg-visual-novel-character-pack-anime-style-sprites-4-characters-4-expr
- Paws & Pixels（对话型视觉小说资产：90 张角色立绘 + 60 张 16:9 场景背景 + 50 个 UI 组件）：https://chiewaters.itch.io/paws-pixels-the-floating-coven-2d-visual-novel-assets
- u8888u 动画 RPG 角色（10 视图含 6 种半身表情，明确列出 bust 表情规格）：https://u8888u.itch.io/anime-rpg-character-41-indigo-silver-harmonica-rover

**适配度评估**

| 维度 | 评价 |
|---|---|
| 与英语学习产品调性 | ★★★★☆ 日式学习游戏（如部分英语学习 App）就用这个 |
| 文字可读性 | ★★★★☆ 需要给立绘加描边或投影，避免与背景粘连 |
| 10 个场景的一致性 | ★★★★☆ 好——背景偏写实+动漫饱和度，需要统一调色 |
| NPC 表情表现力 | ★★★★★ 最强且最规范（表情变体是行业标准做法） |
| 生成难度 | ★★☆☆☆ 难——**同一个 NPC 的多张表情必须脸一致**，AI 最容易在这里崩 |

**最适合**：想要 NPC 有魅力、能表达情绪；愿意为「角色一致性」付出更多调整成本。

## 3. 我的推荐

### 如果只选一个 → **风格 A（现代扁平矢量）**

理由：
1. **不用改 UI 配色**——现有方案书的配色体系直接可用，省一轮返工
2. **AI 生成成功率最高**——24–28 张图的一致性最容易保证
3. **文字可读性最好**——这是语言学习工具，文字是主角
4. 唯一短板是 NPC 表情弱 → **用「表情徽章」补救**：在立绘旁显示小图标（✓ / ? / ✗），比画微表情更有效

### 如果你想要更有温度 → **风格 B（绘本水彩）**

理由：NPC 表情表现力最强、场景有故事感，而且**这是你绘本专业的延伸**——你能自己判断 AI 出的水彩是「对的水彩」还是「假的水彩」，这是别人做不到的质量把关。代价是 UI 配色要转暖。

### 如果你想要 NPC 有魅力 → **风格 E（日式动画）**

理由：表情变体是行业标准做法（4–6 表情 × 多角色），配合「答对/答错」反馈最自然。代价是**角色一致性是最大风险**——同一张脸要出现在 4 张图里，AI 很容易画成两个人。

> **折中方案**：场景图用 A（扁平矢量，好控），NPC 立绘用 E（日式动画，有表情）。两者之间用「统一色调 + 立绘加白色描边」来过渡。这是很多教学游戏的实际做法，成本和效果都比较平衡。

## 4. 选定后要定的三件事

| 问题 | 说明 |
|---|---|
| **纯生成还是买素材？** | 买素材（itch.io 上几十块）质量稳定且风格绝对统一；纯 AI 生成零成本但一致性靠运气。也可以「买 NPC 素材 + AI 生成场景」混合。 |
| **要不要表情变体？** | 每人 1 张静态立绘 + 角标（成本 ≈ 14 张），还是每人 3 张表情（成本 ≈ 42 张）。**后者是成本分水岭。** |
| **立绘是半身还是全身？** | 半身（waist-up）更省空间、更适合 UI；全身更像视觉小说但占地方。 |
